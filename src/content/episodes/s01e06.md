Parts 1 to 5 were about putting files into S3 and managing them. Now someone wants answers from them, like how many orders today have no payment yet. Amazon Athena runs SQL straight on the files in S3, with no database to set up, and it charges for every terabyte a query reads. Whoever writes the file decides its shape, and the shape decides how much Athena reads.
