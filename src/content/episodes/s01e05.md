Every pipeline overwrites and deletes files: a rerun writes the same key, a lookback window rewrites the last three days, a teammate deletes the wrong file. Without versioning, each of those is gone for good. With versioning on, S3 keeps every write as its own version and turns a delete into a marker on top, so the file can be brought back. The kept versions bill in full until a lifecycle rule deletes them, and the same rules move files nobody opens down to cheaper storage, where they have to be restored before anyone can read them.
